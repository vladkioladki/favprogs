## 🎮 Ігри

* **[Gale](https://github.com/Kesomannen/gale)** - програма для модифікації ігор в основному на unity (Lethal Company, Risk Of Rain 2, Among Us etc.)
* **[Limo](https://github.com/limo-app/limo)** - FOSS мод менеджер для ігор від Bethesda
* **[Rare](https://github.com/RareDevs/Rare)** - Epic Games Launcher але без інтерфейсу що знищить вашу оперативну пам'ять. Для тих кому лінь ставити офіційний клієнт.
* **[Hydra Launcher](https://hydralauncher.gg/)** ⭐ - НАЙКРАЩИЙ спосіб безкоштовно скачувати ігри. Є соціальні функції, додавання джерел для скачування та купа всього іншого. Маст хев для тих хто ще досі качає ігри через браузер.
* **[Itch.io](https://github.com/itchio/itch)** - ваші любімі інді ігрушкі
* **[Heroic Game Launcher](https://heroicgameslauncher.com/)** - Один з найкращих лаунчерів для Лінукс чи МакОС.
* **[PCXSense](https://github.com/Denellyne/PCXSense)** - Для тих в кого Dualsense

## 🌐 Браузери

* **[Helium](https://helium.computer/)** ⭐ - Браузер на базі **Chromium** з старим **AdBlock.** Браузер для тих хто любить швидкість хрома.
* **Firefox** - Легендарний браузер, користувався ним довше всього. *Краще ставити [Firefox-ESR](https://www.firefox.com/uk/browsers/enterprise/).*
* **[Zen Browser](https://zen-browser.app/)** - Браузер на основі Firefox, зараз в розробці, тому *можуть бути баги*. Для естетів і тих хто користується вертикальними вкладками.
* **[Floorp](https://floorp.app/)** - Firefox на максималках, кастомізація, підтримка розширень Chrome і ще багато всього.
* **[Vivaldi](https://vivaldi.com)** ⭐ (📱) - Для максимальних естетів. Дуже непоганий браузер ***Мій топ 1 серед браузерів на Android,*** але має закритий код.
* **[Cromite](https://github.com/uazo/cromite)** 📱 - Браузер для Android. Є блокування реклами та багато налаштувань, мобільний хром здорової людини.
